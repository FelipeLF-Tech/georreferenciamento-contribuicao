# Georreferenciamento — participação em projeto de equipe

Felipe Lemos Fonseca contribuiu para este projeto acadêmico em equipe no COMPET PSA. A maior parte do código do projeto foi desenvolvida pelos colegas de Computação; este registro não atribui autoria principal a Felipe. O escopo específico de sua contribuição ainda será detalhado.

O único fonte recuperado para esta publicação é uma API introdutória FastAPI, com rotas `/` e `/workshop/`. Este arquivo NÃO implementa mapas ou georreferenciamento e NÃO representa o sistema GeoSync completo. Não foram publicados código dos colegas, credenciais ou dados de tráfego.

Instale requirements.txt e execute `uvicorn main:app --reload`. Para documentar o sistema completo, adicionar futuramente o link do repositório original e os créditos da equipe.
